# Images

Upload site images here (JPG, PNG, WebP or SVG).

Suggested naming so they're easy to wire into the pages:

- `logo.svg` / `logo-white.svg` — main logo (dark, for the header) and white version (for the footer)
- `hero-<page>.jpg` — page hero, e.g. `hero-home.jpg`, `hero-la-societa.jpg` (wide, ~2880×1100)
- `<page>-<section>.jpg` — other images, e.g. `la-societa-esperienza.jpg` (square ~1320×1320)
- `office-milano.jpg`, `office-trani.jpg`
- `people/<nome-cognome>.jpg` — professional portraits (square)
- `clients/<client>.png` — Track Record client logos (square)
